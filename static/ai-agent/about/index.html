Agent 学习伴侣

关于这个学习伴侣

这是一个独立编写的中文学习系统，用来配合李博杰的开源书《深入理解 AI Agent：设计原理与工程实践》（AI Agents in Depth）。它不是作者、Pine AI 或出版社的官方产品，也不能代替原书。

原书 Copyright 2025 Bojie Li，以 Apache License 2.0 发布。本仓库附有该许可证全文，并在 NOTICE 里说明修改：讲义、练习、测验和界面是重新编写的改编摘要。

  • 在线阅读：https://bojieli.github.io/ai-agent-book/
  • 源仓库：https://github.com/bojieli/ai-agent-book
  • 本伴侣依据 2026-11-19 读取的 main 提交 dbc046eb896a 编写。此后原书若更新，这里不会自动跟上。

覆盖到哪里

十章都有可阅读的短课和 6 道原创测验。第 1 至 5 章依据已读的主要小节编写。第 6 至 10 章依据各章小结，以及已核对的关键段落：评估任务的四个组成部分、Pass@k 与 Pass^k、评估环境五要素、后训练阶段的选择规则、四种进化载体、多 Agent 的两个维度和信息增量判据。

没有覆盖的部分包括：配套实验的操作步骤和代码、思考题参考答案、后记全文、配图、多语言译本，以及未逐段阅读的深水区，例如可编辑 KV Cache、经典强化学习推导、机器人硬件步骤和 Agent 社会案例的细节。那些内容请直接打开原书。

  • 第 1 章 AI Agent 入门

    依据第一章已读正文：公式与环境边界、五类工具、ReAct、Harness、编排顺序、护栏分层，以及贯穿全书的五个设计模式。未收录消融实验的操作步骤和思考题参考答案。

  • 第 2 章 上下文工程

    依据第二章已读正文：四种消息角色、工具调用循环、KV Cache 三条结论、提示与 Skills、状态栏位置、压缩动机和生产分层。未复述注意力实验步骤，也未展开“可编辑 KV Cache”这一深水区。

  • 第 3 章 用户记忆和知识库

    依据第三章已读正文：记忆层次与四种格式、认知科学三类记忆、Mem0 写入策略的演变、RAG 分块与混合检索、RAPTOR/GraphRAG/文件系统范式、智能体化 RAG，以及上下文感知检索和压缩的差别。未收录实验代码和司法案例的数据表。

  • 第 4 章 工具

    依据第四章已读正文：五类工具、ACI、描述与参数保真、MCP 的三类原语、工具过多时的三层发现策略，以及感知、执行、协作的设计重点。事件触发和用户沟通的运行时细节留在第六章，本课不展开未读的异步实现。

  • 第 5 章 Coding Agent 与通用 Agent

    依据第五章已读正文：七个核心工具、项目指令文件、Harness 与四层故障、搜索和编辑方案、致命三要素与持久记忆，以及代码作为元能力的六个方向。未复述 PPT、日志解析和自举实验的实现。

  • 第 6 章 交互：观察与动作空间的扩展

    依据第六章小结，以及引言中对本章结构的说明。讲到异步与时机、三种语音范式、Computer Use 和机器人共享的控制原语。未阅读硬件步骤、具体模型接口参数和实验代码，课文不把那些细节当成已学内容。

  • 第 7 章 Agent 的评估

    依据第七章已读部分：τ²-bench 一条任务的四个组成、评估环境五个要素、Pass@k 与 Pass^k 的计算例子，以及章末小结中的证据链。未阅读全部基准对照、统计检验公式和可观测性实现。

  • 第 8 章 模型后训练

    依据第八章小结中已核对的决策规则：何时用 Mid-training、SFT 或 RL，以及样本效率、on-policy 和奖励路径的高层结论。未阅读可选的经典 RL 推导、具体算法伪代码和三个故障案例的正文，测验不考查那些未读细节。

  • 第 9 章 Agent 的持续进化

    依据第九章已读的四种载体比较、知识与指令的差别、边界集/保留集，以及章末关于在线执行和离线学习分开的小结。未阅读睡眠学习和安全边界小节的全部细则，课文只使用小结里已经写出的结论。

  • 第 10 章 多 Agent 协作

    依据第十章已读的分类、信息增量判据、通信方式和章末失败模式。未阅读 Agent 社会各案例的正文，测验不考查小镇、经济或博弈案例的细节。
